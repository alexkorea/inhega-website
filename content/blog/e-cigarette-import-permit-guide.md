# 전자담배 수입 등록 완벽 가이드 2026

액상형 전자담배(VAPE·베이핑 기기·액상), 가열담배(궐련형 전자담배), 니코틴 파우치 등 전자담배 제품을 수입하여 국내에서 판매하려면 「담배사업법」에 따른 **담배수입판매업 등록**을 하고, 제품별 **성분 표시·검사**와 경고 표시 의무를 지켜야 합니다.

## 1. 전자담배의 법적 분류

「담배사업법」 제2조에 따라 전자담배는 담배의 한 종류로 분류됩니다.

| 종류 | 법적 분류 | 예시 |
|------|---------|------|
| **궐련형 전자담배** | 담배 (궐련 유사) | 아이코스, 릴, 글로 |
| **액상형 전자담배** | 담배 (액상 니코틴 포함 시) | 주스헤드, 나코틴 액상 |
| **니코틴 없는 베이핑** | 담배 아님 (단, 별도 규제 가능) | 무니코틴 허브 액상 |
| **니코틴 파우치** | 담배 (니코틴 원료 시, 머금는 담배) | 화이트 스누스 등 |

> ⚠️ 니코틴이 포함된 모든 전자담배 제품은 담배로 분류되어 수입 시 담배수입판매업 등록이 필수입니다.

## 2. 전자담배 수입 관련 규제 체계

전자담배 수입은 여러 법령의 교차 규율을 받습니다.

| 규제 법령 | 주요 내용 |
|---------|---------|
| **담배사업법** | 수입판매업 등록, 경고문구·성분 표시, 성분 측정, 광고 제한 |
| **국민건강증진법** | 담배 경고 그림·문구 표기 의무, 담배 광고 방법 제한 |
| **담배의 유해성 관리에 관한 법률** | 유해성분 정기검사, 검사결과서 제출 |
| **관세법** | 수입 통관 절차, 관세 납부 |
| **개별소비세법** | 담배 개별소비세 납부 |
| **청소년 보호법** | 청소년(19세 미만) 판매 금지 |

---

## 3. 담배수입판매업 등록 요건

| 항목 | 기준 |
|------|------|
| 공급계약 | 외국의 담배제조업자와 담배 공급계약 체결 |
| 신청 주체 | 법인·개인 모두 가능 |
| 자본금 | 요건 없음 (자본금 기준은 담배제조업 허가) |
| 창고 시설 | 요건 없음 (보관시설은 담배도매업 요건) |
| 등록 기관 | 본점 또는 주된 사무소 소재지 관할 시·도지사 |
| 결격 사유 | 신청인(법인은 대표자)이 결격사유에 해당하지 않을 것 |

## 4. 전자담배 제품 성분 표시·검사

수입 전자담배 제품은 성분을 표시하고, 판매 중인 제품의 성분 측정·유해성분 검사를 의뢰해야 합니다.

| 항목 | 내용 |
|------|------|
| 성분 표시 | 액체형태 담배는 니코틴 용액의 용량을 용기·포장에 표시 |
| 성분 측정 | 분기마다 분기 시작 후 1개월 이내, 재정경제부장관 지정 측정기관에 품목별 의뢰 |
| 유해성분 검사 | 2년마다 연도 개시 후 6개월 이내 검사 의뢰, 검사결과서 등을 식품의약품안전처장에게 제출 |
| 경고 표시 | 국문 경고 그림·문구 인쇄 표기 의무 |

### 전자담배 경고 표시 기준

| 항목 | 기준 |
|------|------|
| 경고 그림 | 담배갑포장지 앞·뒤 각 30% 이상 |
| 경고 문구 | 흡연의 폐해, 니코틴 의존·중독 유발, 담배 특이 니트로사민·포름알데히드 등 포함 사실 |
| 언어 | 한글 표기 |

## 5. 수입 통관 절차

전자담배 수입 시 관세청 통관 절차를 이행해야 합니다.

| 단계 | 내용 |
|------|------|
| 수입 신고 | 관세청 전자통관시스템(UNI-PASS) 신고 |
| 세금 납부 | 관세 + 개별소비세 + 담배소비세 + 국민건강증진부담금 + 부가세 |
| 통관 완료 | 경고 표시가 인쇄된 포장으로 수입, 이후 도매업자·소매인에게 판매 |

### 전자담배 주요 세금

| 세목 | 과세 기준 |
|---------|---------|
| 관세 | 수입 신고 금액 기준 |
| 개별소비세 | 니코틴 용액 1밀리리터당 부과 (연초 고형물 사용 제품은 별도 기준) |
| 담배소비세 | 지방세, 보세구역에서 반출한 담배에 대해 수입판매업자가 납부 |
| 국민건강증진부담금 | 니코틴 용액 1밀리리터당 부과 |
| 부가가치세 | 세율 10% |

세액 계산과 신고는 세무사 등 세무전문가에게 확인하세요.

## 6. 마케팅·판매 규제

전자담배 마케팅은 엄격하게 규제됩니다.

| 규제 항목 | 내용 |
|---------|------|
| **광고 방법 제한** | 소매인 영업소 내부 광고물, 잡지(품종군별 연 10회 이내 등), 행사 후원 등 법에 정한 방법만 허용 |
| **온라인 광고 금지** | SNS·유튜브 등 온라인 광고는 허용된 방법에 없음 |
| **청소년 판매 금지** | 청소년(19세 미만, 19세가 되는 해의 1월 1일을 맞이한 사람은 제외)에게 판매 금지 |
| **판매 장소 제한** | 소매인 지정을 받은 자만 소비자에게 판매, 우편판매·전자거래 금지 |

## 7. 필요 서류

### 담배수입판매업 등록 서류

| 서류 | 비고 |
|------|------|
| 담배수입판매업등록신청서 | 담배사업법 시행규칙 별지 제7호서식 |
| 외국의 담배제조업자와 체결한 담배의 공급계약서 사본 | 1부 |

법인등기부등본·정관·자본금 증명·창고 서류·성분 자료·사업계획서는 등록 신청 첨부서류로 정해져 있지 않습니다.

## 8. 등록 절차 (단계별)

### 1단계: 공급계약 체결

외국의 담배제조업자와 담배 공급계약을 체결합니다.

### 2단계: 결격사유·포장 표시 사전 검토

신청인(법인은 대표자)의 결격사유 해당 여부와, 수입 예정 제품의 경고 표시·성분 표시가 국내 기준에 맞는지 확인합니다.

### 3단계: 시·도지사 등록 신청

담배수입판매업등록신청서에 공급계약서 사본을 첨부해 본점 또는 주된 사무소 소재지 관할 시·도지사에게 제출합니다.

### 4단계: 판매가격 신고

등록증을 받은 뒤 품목별 소비자 판매가격을 판매개시 6일 전까지 시·도지사에게 신고합니다.

### 5단계: 수입 통관

경고 표시가 인쇄된 포장으로 관세청 수입신고와 관세 납부를 마칩니다.

### 6단계: 판매 채널 확보

전자담배를 판매할 도매업자·소매인(소매인 지정을 받은 점포)과 계약을 체결합니다.

## 9. 자주 묻는 질문 (FAQ)

### Q1. 니코틴이 없는 베이핑 액상도 수입 규제를 받나요?
**A**: 연초나 니코틴을 원료로 하지 않은 액상은 「담배사업법」상 담배에 해당하지 않아 담배수입판매업 등록이 필요하지 않습니다. 다른 법령의 적용 여부는 성분과 용도에 따라 따로 확인해야 합니다.

### Q2. 전자담배 기기(기계 장치)만 수입하면 담배수입판매업 등록이 필요한가요?
**A**: 니코틴 액상이나 담배 성분 없이 기기(가열 장치 등)만 수입하는 경우 담배수입판매업 등록은 필요하지 않습니다. 다만 니코틴 용액과 기기가 결합된 1회용 제품은 담배이며, 기기의 전기용품 안전 인증 등은 따로 확인해야 합니다.

### Q3. 전자담배를 인터넷(온라인 쇼핑몰)에서 판매할 수 있나요?
**A**: 아니요. 「담배사업법」에 따라 소매인은 담배(전자담배 포함)를 우편판매·전자거래 방법으로 소비자에게 판매할 수 없습니다. 소매인 지정을 받은 점포(편의점·담배 가게 등)를 통해서만 소비자에게 판매할 수 있습니다.

### Q4. 해외 브랜드 전자담배를 한국에서 독점 판매하려면 어떻게 해야 하나요?
**A**: 해외 제조업자와 **독점 수입 계약**(담배 공급계약)을 체결하고, 그 공급계약서 사본을 첨부해 담배수입판매업 등록을 하면 됩니다. 담배공급자가 바뀌면 변경등록을 해야 합니다.

### Q5. 전자담배 액상의 니코틴 농도 제한이 있나요?
**A**: 담배사업법과 같은 법 시행령·시행규칙에는 액상의 니코틴 농도 상한 규정이 없습니다. 대신 액체형태 담배는 니코틴 용액의 용량을 용기·포장에 표시해야 하고, 판매 중인 제품은 성분 측정과 유해성분 검사를 의뢰해야 합니다.

## 유선행정사사무소의 전자담배 수입 등록 지원

전자담배 수입은 담배수입판매업 등록, 성분 표시·검사, 통관 절차, 경고 표시 기준 준수까지 복잡한 절차가 있습니다. 유선행정사사무소는 전자담배 수입 등록 전 과정을 **원스톱**으로 지원합니다.

### 지원 서비스

- ✅ 전자담배 법적 분류 확인 및 수입 규제 검토
- ✅ 담배수입판매업 등록 신청 대행
- ✅ 성분 표시·검사 의무 안내
- ✅ 경고 표시 기준 준수 안내
- ✅ 변경 등록·폐업 신고 처리
